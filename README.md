## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the Indian Premier League (IPL) dataset using **Python**. The objective is to analyze IPL match data, identify meaningful business insights, and visualize important trends related to teams, players, venues, batting, bowling, toss decisions, and season-wise performance.

The project follows a modular structure and demonstrates real-world data analysis techniques used by Data Analysts.

# ▶️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/IPL-Data-Analysis.git
```

Move to project directory

```bash
cd IPL-Data-Analysis
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python main.py
```
